# MMP Rate Watch

Private Site implementation in site/, mechanical public Marriott observations in checker/, and operating instructions in RUNBOOK.md. The original Claude Artifact dashboard remains in dashboard/ for reference.

This repository now supports a private Sites dashboard with shared D1 data, criteria editing, run requests, stale-result preservation, MCP worker tools, and R2 thumbnails. From site/, follow its README for local setup, migrations, tests, and builds. Live schedule and last-run state are read from the deployed dashboard, not inferred from this repository.
